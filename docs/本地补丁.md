# 本地补丁（PS 2022 / 23.5 适配）

基准：`main @ 6cb817c`（v1.6.1）。安装方式是 `plugin_manager install_bundle` + pnpm link，
`~/.dsh/profiles/desktop/node_modules/dsh-plugin-photoshop` 是指向本目录的 **junction**，
所以改这里的文件＝改实装代码。

## 补丁 1：inspect 遇到没有 ICC 配置文件的文档会整段失败

- **症状**：`photoshop_inspect` 只回一句「Photoshop reported: 没有这种元素」。PS 导出的 PNG
  （例如本插件自己的抠图产物）几乎都不带 profile，全中招。
- **根因**：`lib/jsx.js` 里 `colorProfile: String(doc.colorProfileName)` 没有包 try/catch——
  同一段里其它属性都包了，唯独这一行没包，而 23.5 对无 profile 文档读该属性直接抛错。
- **改法**：先 `try { dshProfile = String(doc.colorProfileName) } catch {}`，再 `colorProfile: dshProfile`。
- **验证**：`ps-smoke/cutout/jianu_original.png`（无 profile）→ 现在正常显示 `profile null`。

## 补丁 2：抠图 / 批处理会关掉用户已打开的同一路径文档（未保存修改丢失）

- **症状**：用户正开着 `A.jpg`（有未保存改动），对同一路径跑 `photoshop_cutout` 或
  `photoshop_batch`，跑完该文档消失，改动一起没了。
- **根因**：23.5 的 `app.open(<已打开文件的路径>)` **复用并返回已存在的 Document**
  （实测 `before=1 after=1`，两次测试都可复现），而收尾 `doc.close(SaveOptions.DONOTSAVECHANGES)`
  关的正是它。
- **改法**：open 前后比 `app.documents.length`；数量没变说明复用了别人的文档，就拿
  `doc.duplicate('dsh-cutout-temp')` / `doc.duplicate('dsh-batch-temp')` 干活，只关副本。
- **涉及**：`lib/jsx.js` 的 `dshCutoutOne`、`lib/ops-jsx.js` 的 `dshBatchOne`。
- **验证**：脏文档 + 同路径抠图后 `docs=1 [jianu_original.jpg(dirty)]`，输出 PNG 正常。

## 本地增强（上游没有的功能，本地加的）

### 1. `place_image` —— 往现有文档里贴外部图片
`photoshop_apply` 新增操作，把一个图片文件作为新图层放进当前文档（贴 logo、水印、换背景、合成详情页）。
参数：`path[, name, width, height, max_side, x, y, center, opacity, blend_mode]`。
- 实现：`app.open` 打开源图 → `activeLayer.duplicate(target, ElementPlacement.PLACEATBEGINNING)` → 关源文档。
  Photoshop 自带的 `placeEvent` 会弹模态框，脚本按不掉，所以不走它。
- 尺寸按「框」算：同时给 width+height 时等比装进去（contain），给 max_side 时封最长边；`x`/`y` 是图层左上角；`center: true` 直接居中。
- 源文档带 `alreadyOpen` 判断：如果这个文件用户本来就开着，不去动它。
- 实测：1200×1200 画布贴 2560 高的抠图，`max_side 420` → 146×419 @ (100,80)，比例正确。

### 2. 文字排版参数（`add_text` / `set_text`）
在原有 `contents/name/size/color/font/justification/x/y` 之外新增：
- `tracking`：字距，单位 1/1000 em
- `leading`：行距，像素值，或字符串 `"auto"`
- `horizontal_scale` / `vertical_scale`：横/纵向缩放，百分比
- `baseline_shift`：基线偏移，像素
- `x`/`y` 现在单独给一个也行（只挪一个轴）

**坑**：ExtendScript 的 DOM 属性叫 `useAutoLeading`，不是 `autoLeading`。直接写 `autoLeading` 会被静默忽略，
之后读 `textItem.leading` 抛「文本设置为自动行距，并且没有特殊的行距值」——必须先把 `useAutoLeading` 设 false 再赋 `leading`。

### 3. `photoshop_inspect` 现在会回报排版
文字层额外输出 `tracking N · leading 48px|auto · scale N%`，排版是否落地不用靠眼睛看。

操作总数：93 → **94**（`photoshop_reference` 已列出 `place_image`）。

## 生效 / 回退 / 升级

- **生效**：`plugin_manager set_plugin target=include:tool-photoshop enabled=false`，再 `enabled=true`。
  重新 apply 会重新 import，补丁立即生效，不必重启 dsh（实测有效）。
- **回退**：`git -C <本目录> checkout -- lib/`。
- **升级**：重新 clone 或拉到新版本会覆盖这两个补丁，需要重打（先看上游是否已修）。
